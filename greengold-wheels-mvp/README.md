# GreenGold Wheels MVP

Bağımsız, statik ve gömülebilir araç kiralama karbon katkısı demosu. `index.html` doğrudan açılabilir.

Demo formülü: `mesafe (km) × araç faktörü (kgCO₂e/km) = kgCO₂e`. Gösterilen faktörler yalnızca prototip amaçlıdır. Canlı kullanımda faktörün kaynağı, ülkesi, yılı, araç/yakıt sınıfı ve kapsamı kayıt altına alınmalıdır.

Akış: araç seçimi → tahmini mesafe → widget'ta etki/katkı → kullanıcı onayı → ödeme toplamına ekleme → rezervasyon sonrası sertifika/kanıt.
